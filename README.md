# ScarletPic

A fast image archive with dark red glass styling, color and palette filters, and browser-local favorites. The collection includes 8,170 images across 12 color groups.

## Browse the collection

- Numbered pages, previous/next controls, and 48, 96, or 192 images per page.
- Color, palette, and tag filters combine with search. Multiple search words use AND.
- Multicolor, limited-palette, and monochrome groups; landscape, portrait, and square tags.
- A virtualized grid keeps only a small window of cards in the DOM. Thumbnails start loading when visible, with at most four requests at once. Larger files load when their viewer opens.
- Skeletons, image fade-ins, retry states, a keyboard-friendly viewer, hex copying, and WebP downloads.
- Favorites and personal tags are stored in the current browser. Export/import a backup through **Tags & tools**.

The default page contains 96 images, giving the collection 86 pages. Pagination and filters are reflected in the URL. The gallery contains no outbound source-profile links, source credits, or automatic redirects.

### Keyboard controls

| Key | Action |
| --- | --- |
| `/` | Focus search |
| Left / Right | Previous / next image in the viewer |
| `S` | Save or unsave the current viewer image |

## Run locally

No application dependencies need installing. Serve the public directory over HTTP:

```sh
python -m http.server 8000 --directory public
```

Open `http://localhost:8000`. Opening the HTML file directly will not load the JSON catalogue.

Node 20 or newer is used for repository checks and sitemap generation:

```sh
npm run check
npm run build
```

## Deploy to Netlify

Import this repository in Netlify. The included `netlify.toml` sets:

| Setting | Value |
| --- | --- |
| Build command | `node tools/build-site.mjs` |
| Publish directory | `public` |
| Application dependencies | None |

The build writes `robots.txt`, the paginated image `sitemap.xml`, and canonical metadata using Netlify's production `URL`. Set `SITE_URL` if you want to override that address. No placeholder domain is published by the build.

For an already assigned domain, you can generate the files manually:

```sh
node tools/build-site.mjs --site-url https://your-actual-domain.com
```

Replace the example address with your own origin. You can then deploy `public/` using Netlify Drop or the CLI. The `public/_headers` file preserves cache and security headers for a folder deploy.

Before a public origin is assigned, the checked-in sitemap is intentionally empty and documented as pending. The Netlify build populates all 86 page URLs and image locations. `robots.txt` remains valid while the address is unknown.

`rules.txt` describes collection usage and polite automated access. It is advisory, not an access-control or rate-limiting system. A custom `404.html` is included. No redirect rules are configured.

The site includes 16,340 media files: 320px cropped thumbnails and larger optimized WebP copies. Keep both media directories. Downloads return WebP copies; the original JPEG archive is separate.

## Tags and optional AI

| Tag source | Meaning |
| --- | --- |
| Average color | Arithmetic average of every RGB pixel, assigned to a named color group |
| Palette | Hue-coverage heuristic from a 96px sample |
| Shape / brightness | Measured aspect ratio and very dark or bright averages |
| Caption tags | Imported context; may describe a group rather than each image |
| AI tags | Optional predictions generated by a local model |
| Your tags | Explicit annotations added in the browser |

Multicolor requires three hue groups covering at least 6.5% of the sample each. Monochrome has less than 5.5% chromatic coverage. The remaining images use limited palette. These labels are heuristics, not semantic AI classifications.

The bundled dataset now includes **104,746 AI predictions across all 8,170 images**, averaging 12.82 predictions per image, with 2,689 distinct tags. 8,170 images were processed through DirectML on a Radeon RX 6700 XT. These tags are loaded automatically by the gallery. Character predictions remain unreviewed.

The included tool uses [SmilingWolf's WD14 model](https://huggingface.co/SmilingWolf/wd-swinv2-tagger-v3) for anime attributes and character predictions. It downloads model weights on first use, runs inference locally, checkpoints progress, and resumes. Images are not uploaded. CPU and Windows DirectML providers are supported.

```sh
python -m pip install -r tools/requirements-ai.txt
python tools/tag_ai.py --limit 10
python tools/tag_ai.py
```

For an AMD GPU on Windows, use a separate environment with the DirectML runtime:

```powershell
python -m venv .venv-dml
.venv-dml\Scripts\python.exe -m pip install -r tools/requirements-ai-directml.txt
.venv-dml\Scripts\python.exe tools/tag_ai.py --provider auto --batch 4
```

`--provider auto` prefers DirectML when installed and falls back to CPU if initialization or inference fails. `--provider directml` requires GPU execution-provider initialization and stops on failure; `--provider cpu` selects CPU explicitly. Device 0 is the default adapter; use `--device-id` for another adapter. DirectML may leave unsupported graph operations on CPU. The GPU was tested on a Radeon RX 6700 XT.

Do not install `onnxruntime` and `onnxruntime-directml` into the same environment; both provide the same Python module. `--offline` uses cached model files without a network request. `--output` writes a separate JSON file for a trial without changing the published dataset.

Results go to `public/data/ai-tags.json`. Redeploy the site to publish them, or import that JSON through **Tags & tools** for browser-local use. Model weights are cached outside `public/` and ignored by Git. Predictions can be wrong; review them before relying on character labels.

General and character thresholds default to 0.35 and 0.85. Lowering `--threshold` accepts more general tags, with more false positives; `--character-threshold` controls character predictions separately. Higher thresholds keep fewer predictions. To change thresholds, back up the existing JSON and use a new `--output` file so incompatible runs cannot silently mix. Lowering a threshold requires inference again because only accepted predictions are saved. You can add personal tags in the browser independently of the model.

WD14 is not a reliable anime-versus-photograph classifier; a CLIP-style model can complement it for broad visual styles. [TagGUI](https://github.com/jhc13/taggui) is another option for local batch tagging and review.

## Project layout

```text
public/
  index.html              Gallery
  404.html                Missing-page view
  assets/                 UI, fonts, icons, wheel smoothing
  data/                   Catalogue and optional AI tags
  media/thumbs/           Viewport thumbnails
  media/images/           Larger WebP viewer copies
  robots.txt
  sitemap.xml
  rules.txt
tools/
  build-site.mjs          Canonical metadata and sitemap generation
  check-site.mjs          Dependency-free validation
  tag_ai.py               Optional local anime tagger
licenses/                 Third-party notices
site.config.json          Optional production origin
netlify.toml              Build and hosting settings
verification.json         Recorded verification scope
```

The interface uses self-hosted Panchang and Pilcrow Rounded, Tabler icons, and Lenis wheel smoothing. Its small native WebGL background follows the supplied Yume dither direction. Motion follows that reference's explicit policy; the shader pauses in hidden tabs.

## Checks

`npm run check` covers catalogue counts, pagination boundaries, filter combinations, saved selection, search, tag normalization, sitemap URLs, local references, startup image loading rules, branding, and removal of source-profile links.

JavaScript and Python syntax, media headers and dimensions, and archive CRCs have also been checked. Browser automation was blocked by the tool's URL policy in the build session, so visual and responsive browser behavior is not claimed as verified. All 8,170 images have AI results. A 64-image CPU/DirectML comparison produced identical accepted tag sets, with shared scores differing by at most 0.0001. Coverage, score validity, tag uniqueness, and combined tag searches are checked. This is a consistency check, not an accuracy benchmark.

## Privacy and rights

The hosted app has no account system, analytics, remote fonts, image uploads, or automatic model requests. Favorites and personal annotations remain in the current browser until exported. Older collection backups remain importable.

Hosting this collection publicly makes its image files publicly accessible. Artwork rights remain with their respective owners. Public access is not an additional artwork license. Font and library notices are retained in `licenses/` and beside the font files.
